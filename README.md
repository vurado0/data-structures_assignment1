## About

This program loads a BMP image and processes its pixels using linked stacks, a queue, and a list of rows. It can search for a colour, sort each row by a selected colour component, and mirror the original image horizontally.

## Build and run

1. Open `DS-LabAssignment1.workspace` in CodeLite.
2. Set the `Assignment1` project as the active project.
3. Build with **F7**.
4. Run the program and enter an image filename when prompted, such as `small.bmp`.

The test images are in the `Assignment1` folder: `small.bmp`, `mid.bmp`, and `big.bmp`.

## Menu

1. Search for pixels with a specified RGB colour.
2. Sort each row by red, green, or blue.
3. Reconstruct and mirror the original image horizontally.
4. Exit.
